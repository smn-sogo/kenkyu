# ワークシートPDFのGoogle Drive登録方法

Version 0.5では、ワークシートPDFの保存場所としてGoogle Driveを使用します。閲覧する生徒・教員にはGoogle Driveを意識させず、商業探究アーカイブ内でPDFを表示します。

## 投稿する先生の作業

1. Google DriveへワークシートPDFをアップロードします。
2. PDFを右クリックして「共有」を開きます。
3. 「一般的なアクセス」を **リンクを知っている全員** に変更します。
4. 権限は **閲覧者** にします。
5. 「リンクをコピー」を押します。
6. 商業探究アーカイブの登録画面に、その共有リンクを貼り付けます。

## 管理画面に表示する案内（Version 0.6実装予定）

Google Drive URL入力欄の近くに、以下を常時表示する仕様です。

- 「Google Driveを開く」ボタン
- 「PDFをアップロード後、共有設定を『リンクを知っている全員』『閲覧者』にしてください。」という案内
- Google Drive共有URLの入力欄

これにより、管理者がJSONファイルを直接編集する必要はありません。

## 注意

共有設定が「制限付き」のままだと、他校の生徒・教員がPDFを閲覧できません。
